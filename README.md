# 🏨 MauiAppHotel

Aplicativo desenvolvido como projeto acadêmico para praticar o desenvolvimento de interfaces gráficas utilizando **.NET MAUI**, **C#** e **XAML**.

## 📌 Sobre o projeto

O **MauiAppHotel** é um projeto com temática de hotelaria, criado com o objetivo de explorar os recursos de desenvolvimento de aplicações mobile e a construção de interfaces utilizando os componentes disponíveis no .NET MAUI.

O projeto faz parte dos estudos de Programação Mobile I.

## 🛠️ Tecnologias utilizadas

- **C#** — linguagem de programação.
- **.NET MAUI** — framework para desenvolvimento multiplataforma.
- **XAML** — criação e organização das interfaces gráficas.
- **Visual Studio** — ambiente de desenvolvimento.

## 🎯 Objetivos

- Praticar o desenvolvimento de aplicações com .NET MAUI.
- Conhecer e utilizar componentes de interface gráfica.
- Trabalhar com organização de páginas e elementos visuais.
- Desenvolver uma aplicação com temática de hotel.

## ▶️ Como executar

1. Faça o download ou clone este repositório:

   ```bash
   git clone https://github.com/GuhDev97/MauiAppHotel.git
   ```

2. Abra a pasta do projeto.

3. Abra o arquivo `MauiAppHotel.slnx` no Visual Studio.

4. Aguarde o carregamento das dependências.

5. Selecione o dispositivo ou emulador desejado.

6. Execute o projeto.

> É necessário ter o ambiente de desenvolvimento .NET MAUI configurado no Visual Studio.
